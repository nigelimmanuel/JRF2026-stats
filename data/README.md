# Dataset

Semua CSV di folder ini adalah hasil lomba JRF 2026 yang di-scrape dari halaman publik
[results.scorenow.co.id](https://results.scorenow.co.id), tanpa perubahan isi selain format CSV.

Dataset ini **tidak** termasuk lisensi MIT (script) maupun CC BY 4.0 (chart) di repo ini. Hak atas data
hasil lomba tetap ada pada penyelenggara JRF 2026 dan scorenow. Data disediakan apa adanya untuk
keperluan analisis dan membuat ulang chart; cantumkan scorenow sebagai sumber bila memakainya.
